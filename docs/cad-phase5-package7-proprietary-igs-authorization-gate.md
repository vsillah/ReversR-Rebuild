# Phase 5 Package 7 proprietary IGS authorization gate

Status: public-safe preparation only. Package 7 is not started and no proprietary file authority exists.

This packet adds no architecture, adapter, checker, implementation, route, provider, account action, storage, conversion, download, deployment, or release authority. It reuses the Package 7 acceptance and rollback boundaries in `docs/cad-phase5-private-igs-activation-plan.md`.

## Exact authorization fields

Every field below must be supplied together and explicitly approved before the bounded run. Sensitive values belong only in the approved restricted destination; this public-safe artifact records requirements, not values.

| Required field | Exact requirement |
| --- | --- |
| Proprietary input binding | One absolute local file path or one exact conversation attachment identity. Do not place the value in public evidence. |
| Owner consent | Named owner or authorized custodian, affirmative consent, consent date, and scope permitting this one qualification run. |
| Classification | Exact data classification and handling restrictions for source, derived geometry, logs, screenshots, and receipts. |
| Operator | One named person authorized to initiate the single attempt. |
| Backup operator | One named backup who can perform recovery or deletion but cannot create a second attempt. |
| Deployment binding | Exact non-production or production-equivalent deployment identifier, URL, and reviewed commit binding. |
| Test account | Exact synthetic/internal test-account identity reference with current owner/shop entitlement; no credential may appear in the packet. |
| Retention | Exact maximum retention for the original and for each derived artifact. |
| Deletion deadline | One absolute UTC deadline covering original, derived, temporary, evidence, and documented log/backup disposition. |
| Cost cap | One enforceable maximum amount and metered usage ceiling; an estimate without a hard stop is insufficient. |
| Attempt window | One absolute UTC start and end time, one attempt maximum, and zero automatic retries. |
| Restricted evidence destination | Exact approved location for private operational evidence, access list, and retention/deletion rule. |
| Public evidence destination | Exact approved location for sanitized booleans, bounded counts, and opaque receipt references only. |
| Incident owner | One named person responsible for access anomaly, cleanup ambiguity, retention failure, or evidence leakage. |
| Stop owner | One named person empowered to close admission, revoke the session/cohort and grants, stop compute, quarantine uncertainty, and order deletion. |

Approval must also preserve these stop conditions: any unknown outcome, cleanup ambiguity, access-control anomaly, fidelity failure, cap breach, or evidence leak stops the run with no retry.

## No-touch boundary before approval

Until the exact completed packet is approved, no candidate proprietary file may be discovered, opened, read, hashed, copied, renamed, attached, uploaded, rendered, converted, or named in public evidence. No credential, session, account, provider, configuration, deployment, request body, storage object, download grant, payment, or external message may be created or used.

## Existing acceptance and rollback

After authorization, the unchanged Package 7 acceptance criteria remain authoritative: the approved original enters only approved custody; its owner can view the derived model and retrieve the byte-identical original plus bound STL; another user/shop cannot discover or access it; cleanup and the hard cap are confirmed; retention/deletion completes by the approved deadline; and any uncertainty stops without retry.

The unchanged rollback remains close-first: close admission and conversion authority, revoke the exact session/cohort and grants, stop known compute, quarantine unknown state, execute the approved private-object deletion plan, and run read-only reconciliation. Rollback never authorizes a second attempt.

## Authorization handoff

Send one approval message containing all required values above and the sentence: `I authorize exactly one Package 7 proprietary IGS qualification within this packet and no retries.` Supplying or approving the packet authorizes only the bounded run; it does not authorize merge, production release, general availability, or Package 8.
